# 데이터 출처

- 데이터명: 서울시 응급실 위치 정보
- 제공기관/저작권자: 서울특별시
- 공식 페이지: https://data.seoul.go.kr/dataList/OA-20338/S/1/datasetView.do
- 데이터셋 ID: OA-20338
- 다운로드: 공식 페이지 Sheet의 CSV 내려받기 기능
- 다운로드 일자: 2026-11-01 (한국 시간)
- 이용허락: 공공누리 제1유형, 출처 표시 조건으로 상업적 이용 및 변경 가능
- 프로젝트 파일: `서울시 응급실 위치정보.csv`

내려받은 파일에서 헤더를 제외한 **77개 데이터 행, 34개 열**을 확인했습니다.
원본 CSV는 CP949이며, 프로젝트에는 동일한 내용을 UTF-8 BOM으로 변환해 저장했습니다.
열 이름과 데이터 값은 수정하지 않았습니다.
